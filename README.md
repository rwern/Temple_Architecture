# Tamil Temple Architecture AI

A Streamlit application that explores Tamil temple architecture and uses Google's Gemini AI to analyze temple details.

## Features
- **Temple Explorer**: Browse details of famous Tamil temples.
- **AI Analysis**: Use Gemini 2.5 Flash to generate architectural insights.
- **Interactive UI**: Clean and responsive design.

## Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the app: `streamlit run Temple_App.py`.

## Configuration
You need a Google Gemini API key to use the AI features. Enter it in the sidebar when running the app.
